# Shelf

Site do Shelf: auditoria de estoque e quebra para o varejo alimentício.

Publicado com GitHub Pages a partir da branch `main`. O site inteiro está em `index.html` (logomarca, ilustração e ícones embutidos).

## Formulários

Os pedidos de demonstração e as mensagens precisam de um endereço que receba os dados. Em `index.html`, procure por `CONFIG` e preencha `endpoint` (qualquer serviço que aceite POST em JSON, como Formspree ou um webhook de CRM), `email` e `whatsapp`. Enquanto o `endpoint` estiver vazio, o visitante recebe um resumo do pedido para enviar por e-mail ou WhatsApp.

## Pendências

Textos entre colchetes, como `[E-MAIL]`, `[PREÇO]` e `[CNPJ]`, aguardam definição do time.
